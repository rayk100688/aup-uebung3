# aup-uebung3
tasks for learning the language "Rust"

Aufgabe1

Erstellen Sie eine Funktion welche ein Array mit den ersten 20 Fibonacci-Zahlen füllt

Aufgabe2

Erstellen Sie eine Funktion, welche ein Array aus 10 Werten gespiegelt zurückgibt

Aufgabe3

a)Erstellen Sie eine Funktion welche ein zweidimensionales Array auf der Konsole ausgibt. Wie lässt sich ein zweidimensionales Array darstellen? Wie muss die Signatur der der Funktion aussehen?

b)Erstellen Sie eine Funktion, welche ein zweidimensionales Array transponiert (Zeilen und Spalten vertauscht) auf der Konsole ausgibt.

c)Erstellen Sie eine Funktion, welche das Produkt zweier Matritzen zurückgibt.

Aufgabe4

Erstellen Sie eine Funktion welche das Kreuzprodukt von zwei 3D-Vektoren(x,y,z) bildet und zurückgibt (alles Tupel, nur f32)

Aufgabe5

Gegeben ist fas Sruct:

struct Person {
  age:u8,
  name:[char;10],
}

a) erstellen Sie eine Funktion welche für ein Array von Personen das durchschnittliche Alter zurückgibt

b) erstellen Sie eine print-Methode für das Struct Person innerhalb des Struct-eigenen Traits

c) erstellen Sie eine Methode für das Struct Person innerhalb des Struct-eigenen Traits, welche die Person mit längeren Namen zurückgibt
